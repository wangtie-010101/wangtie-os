快速启动：
1. 解压，进入 wangtie-os 文件夹。
2. 准备 Node.js（本次测试版本 24.19.0）和 npm。
3. 执行 npm ci --legacy-peer-deps
4. 执行 npm run build
5. 执行 npm run preview
6. 浏览器访问 http://127.0.0.1:3081/wangtie-os/ ，左侧选择「OceanBase 管理」。

功能范围：工作台、OceanBase 管理（Oracle 兼容模式：模式/表/字段浏览，表数据查询、新增、编辑、删除及
当前页 CSV 导出；不含建表、删表，只支持 Oracle 模式租户）、DDL 比较（SIT ↔ UAT 表结构差异，连接信息读
config/ddl-environments.json，页面不回传密码、不下发 DDL）、知识库（票据/会计）、数据字典、记事本、
常用开发工具、休息一下、健康提醒。

已移除：SQL 查询（演示）——自定义数据库连接 + Mock SQL 编辑器，及其后端 /api/db/test、/api/sql/*。
原侧边栏里那一项名叫「数据查询」，其实就是 OceanBase 页面，现已恢复并统一改名为「OceanBase 管理」。

验证：单元/交互检查、真实 MariaDB 兼容链路及浏览器操作已通过；OceanBase 本体兼容性尚未完成验证。
详细结果见 docs/OceanBase验收记录.md。
