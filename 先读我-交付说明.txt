王铁 OS · OceanBase 菜单交付包
整理日期：2026-09-17

内容：完整项目源码、服务端/客户端构建结果、依赖锁文件、测试代码、使用说明和验收记录。
不含：node_modules、Git 历史、本机测试数据库及数据库密码、临时下载文件。

快速启动：
1. 解压，进入 wangtie-os 文件夹。
2. 准备 Node.js（本次测试版本 24.19.0）和 npm。
3. 执行 npm ci --legacy-peer-deps
4. 执行 npm run build
5. 执行 npm run preview
6. 浏览器访问 http://127.0.0.1:3081/wangtie-os/ ，选择左侧 OceanBase 管理。

功能范围：OceanBase MySQL 兼容模式，数据库连接、库表/字段浏览、表数据查询、新增、编辑、删除及当前页 CSV 导出。不含建表、删表或 Oracle 模式。
验证：单元/交互检查、真实 MariaDB 兼容链路及浏览器操作已通过；OceanBase 本体兼容性尚未完成验证。详细结果见 docs/OceanBase验收记录.md。

npm test：运行单元与交互测试。
npm run typecheck：运行全项目类型检查。
npm run test:integration：需单独准备专用测试实例和配置，包内不附数据库密码。详见 docs/OceanBase使用说明.md。

如果需要安装到 DSH Web，请参考 README.md 及 docs/OceanBase使用说明.md。
文件清单.sha256 可用于核对源码和构建文件是否完整。
