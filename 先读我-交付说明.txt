【方式一】装成 DSH 插件：启动 dsh 就加载王铁 OS（推荐，目标机上有 DSH 时用这个）
1. 解压，进入 wangtie-os 文件夹（包内已带构建产物与 node_modules，无需 npm install / npm run build）。
2. 执行 node scripts/install-to-dsh.mjs
   纯文件操作：把包放到 <profile>/node_modules/wangtie-os、在 profile 的 dsh.profile.bundles 里登记 wangtie-os、
   写一条 file: 依赖；不需要 pnpm、不需要联网，会先备份 profile 的 package.json，可重复执行（--dry-run 可预览）。
3. 重启 dsh web（宿主半边只在进程启动时 import 一次）。
4. 浏览器访问 http://127.0.0.1:3080/wangtie-os/  ← 走 DSH 自己的 3080 端口，不再需要 3081。
   核对 http://127.0.0.1:3080/wangtie-os/api/health ：routes 应列出 22 条，debug.mountState 应为空。
   卸载：node scripts/install-to-dsh.mjs --uninstall
   详见 docs/安装到DSH.md。

【方式二】不装 DSH 时的离线预览（默认端口 3081）
1. 解压，进入 wangtie-os 文件夹。
2. 准备 Node.js（本次测试版本 24.19.0）。
3. 执行 npm run preview（端口可用 PORT=xxxx 覆盖）
4. 浏览器访问 http://127.0.0.1:3081/wangtie-os/ ，左侧选择「OceanBase 管理」。
   如需重新构建：npm ci --legacy-peer-deps && npm run build（包内已含构建产物，通常不必）。

功能范围：工作台、OceanBase 管理（Oracle 兼容模式：模式/表/字段浏览，表数据查询、新增、编辑、删除及
当前页 CSV 导出；不含建表、删表，只支持 Oracle 模式租户）、DDL 比较（SIT ↔ UAT 表结构差异，连接信息读
$DSH_HOME/wangtie-os/ddl-environments.json 或包内 config/ddl-environments.json，页面不回传密码、不下发 DDL）、
知识库（票据/会计）、数据字典、记事本、常用开发工具、休息一下、健康提醒。
